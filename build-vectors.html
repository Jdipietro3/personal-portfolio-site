Build search vectors

Generates search-vectors.js so visitors don't pay ~4s of on-device inference to embed the page's own content. This is a build tool, never linked from the site. Run it over http://, not file://.

When to re-run

  1. Any time you edit content.js, or change chunking in search-index.js.
  2. Forgetting is safe: search-vectors.js stores a hash of what it was built from, and the site silently falls back to live embedding if it no longer matches. You'll see a console warning, not broken search.
